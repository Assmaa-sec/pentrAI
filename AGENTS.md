# Agent instructions for PentrAI

Read `CODEX.md` in full before working in this repository and follow its mandatory workflow and security rules.

## Mandatory UI skills

For every UI design or implementation task in this repository, use all three installed Codex skills:

1. `interface-design` — establish the product-specific visual direction, hierarchy, and design-system decisions.
2. `vercel-react-best-practices` — apply its React guidance while writing, reviewing, or refactoring UI code.
3. `web-design-guidelines` — review the resulting interface for usability, accessibility, and web design issues.

Read each skill's `SKILL.md` before the relevant work. Apply the three skills together for new UI, changes to existing UI, and UI reviews; do not treat any one as a substitute for the others. Report any skill that could not be used and why.
